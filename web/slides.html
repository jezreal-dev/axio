SLIDE 03 / 08 · THE SOLUTION 2. How Axio Solves the Challenge

Axio: Scientific Hypothesis Falsification Across Disconnected Silos

Instead of guessing or summarizing tickets, Axio treats root-cause investigation as a formal mathematical elimination tournament:

4 Deterministic Evaluator Falsification Rules

  • 1. Temporal Precedence Check (cause_ts ≤ onset_ts): Automatically rejects any deployment or flag change that occurred after the earliest anomaly trace in {telemetry}.api_traces.
  • 2. Contract & Ledger Contradiction Check: Reconciles customer support claims against {billing}.subscriptions and {billing}.plan_changes.
  • 3. Two-Proportion Cohort Z-Test & Risk Ratio: Computes in-cohort vs. out-of-cohort failure rates ($z > 3.29, p < 0.001$) to prove fault isolation.
  • 4. Primary-Key Citation & Retry Deduplication: Enforces multi-silo row citations and deduplicates financial impact via COUNT(DISTINCT billing.checkout_events.event_id).

What the User Gets in Under 2 Seconds

  • Visual Falsification Graph: Shows Round-1 war-room decoys rejected in red with exact SQL math proofs, and the true Round-2 root cause verified in green.
  • Deduplicated Dollar-Impact Audit: Separates gross retried failure volume from net lost revenue and hourly burn rate.
  • Actionable Remediation Runbook + Verification SQL: Step-by-step rollback instructions plus a copy-paste Zetaris SQL query enforced by FinalReviewerAgent.

SLIDE 06 / 08 · UNIQUE SPONSOR INNOVATION 6. What Was Unique About Our Use of Sponsor Technologies

Three Architectural Innovations Combining Zetaris, Meterless & Nemotron

1. Zetaris Schema Introspection → Meterless H-MEM Procedural Learning

In Round 1, ExecutorAgent queries {billing}.checkout_events using telemetry column names (timestamp, platform). When SQL fails, ZetarisAdapter introspects the billing schema via describe(), repairs the columns to created_at and device_os (TOOL_ERROR_RECOVERY), and stores a procedural memory in Meterless H-MEM. In Round 2, ExecutorAgent retrieves that H-MEM memory and executes clean SQL on the first try!

2. Adversarial Falsification State in Meterless World Model

Rather than using Meterless as passive chat history, Axio models every war-room hypothesis as a first-class World Model entity with explicit state transitions (TESTING → FALSIFIED / VERIFIED) and continuity anchors. Re-injected World Model context prevents PlannerAgent from ever re-proposing a falsified red herring.

3. Cost-Aware NVIDIA Nemotron Dual-Lane Routing

High-frequency SQL execution, schema repair, and H-MEM event distillation route to the low-latency Fast Lane (nvidia-nemotron-nano-9b-v2), while multi-hypothesis causal decomposition and adversarial falsification route to the Reasoning Lane (llama-3.3-nemotron-super-49b-v1).
